# Task 4: Classification with Logistic Regression

## Objective

Build a binary classification model using Logistic Regression.

## Dataset

Breast Cancer Wisconsin dataset stored in `DATA/data.csv`.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Work Completed

* Data inspection and preprocessing
* Training, validation, and test split
* Feature scaling and categorical encoding
* Logistic Regression model training
* Accuracy, precision, recall, and ROC-AUC evaluation
* Confusion matrix and ROC curve visualization
* Sigmoid function visualization
* Classification threshold comparison

## Project Files

* `DATA/data.csv` — Dataset
* `Logistic_Regression.ipynb` — Main notebook
* `requirements.txt` — Required libraries

## How to Run

1. Install the libraries using `pip install -r requirements.txt`.
2. Open `Logistic_Regression.ipynb` in VS Code.
3. Run the notebook cells in order.

## Results

See the final test evaluation in the notebook.

## Conclusion

This project demonstrates binary classification with Logistic Regression and evaluates model performance using several classification metrics.
